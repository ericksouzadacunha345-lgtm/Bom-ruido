Sobre o Projeto

Trabalho de Conclusão de Curso

Sistema Inteligente de
Monitoramento de Ruído

Uma solução tecnológica para registrar e visualizar níveis de ruído no ambiente escolar, com uma configuração preventiva opcional para o Modo TEA.

Objetivo

Monitorar em tempo real os níveis de ruído nas salas de aula utilizando sensores conectados a um microcontrolador ESP32, fornecendo dados precisos para professores e gestores.

Controle de Ruído

O sistema registra níveis de ruído, classifica as leituras conforme limites configurados e fornece histórico para acompanhamento do ambiente escolar.

Modo TEA

O Modo TEA funciona como uma configuração preventiva do sistema. O limite é definido pelo usuário e não representa diagnóstico, recomendação clínica ou limite médico.

Benefícios

Alertas em tempo real, histórico de dados, relatórios para gestores escolares e uma interface intuitiva que transforma dados de sensores em ações pedagógicas concretas.

Desafio das Salas — Competição de silêncio

A sala acumula pontos por permanecer dentro do limite de ruído. O ranking é calculado com os dados registrados no servidor.

    Fonte de Dados

    Simulação gera dados somente para testes. O modo Microfone lê o microfone deste computador. O modo Sensor Real recebe leituras pela API.

    Conecte o microfone USB e selecione-o aqui. Se ele for o dispositivo padrão do sistema, deixe a opção automática.

    No celular ou tablet, o navegador pedirá permissão. Para acesso remoto, o site precisa estar publicado em HTTPS. O microfone pode permanecer desconectado até chegar; a configuração fica salva.

    Um microfone USB representa uma fonte de áudio por vez. Escolha qual sala receberá as leituras.

    Padrão: /api/s10/latest. O S10/ESP32 envia as medições para /api/s10/ingest usando o cabeçalho x-s10-key. Use HTTPS quando publicar o servidor.

    OfflineAPI S10 aguardando leituras

    Ainda não calibrado

    Sem calibração, o sistema mede dBFS (nível relativo do sinal). Para apresentar dB estimado, informe um offset obtido por calibração com equipamento de referência. Não há um valor padrão universal.
